Entry for the [make.fun bounty "One Sentence for a Traveler from 1800"](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb): one sentence of at most 200 characters explaining the modern internet to someone arriving from 1800.

## The sentence

> Imagine every letter ever written, arriving instantly, carried by lightning trapped in glass you hold in your hand.

## How it works

`main.ts` writes the sentence to `/output/entry.txt` (115 characters, one sentence), after checking it against the competition gate: 1–200 characters, not only whitespace, exactly one sentence — then reads the file back and verifies it byte for byte.

Run it with Node 22 or later:

```sh
node main.ts
```
